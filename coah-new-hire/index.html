1.2 iOS 端（iPhone / iPad）— 仅中国 iOS 同事

适合机型：iOS 15 及以上。

  1. 获取 Apple ID（iOS 中国同事必须；销售助理跳过此步）· 第一阶段（临时）：使用 Thomas 提供的美区 Apple ID 账号密码，登录 App Store。仅下载需要的 App，不要登录 iCloud。
说明：先使用 Thomas 的账户是因为目前还没有稳定的国际上网环境。登录美区 App Store 需要先连上 VPN 并选美国节点，注册美区 ID 也是一样。等完成 §1 的网络配置后，每位 iOS 中国同事就可以用自己的美区 ID 操作了。

销售助理说明：销售助理在印尼，不需要美区 Apple ID。印尼区 Apple ID 已经能下载非常多常用软件（包括 Loon 等），无需特殊账号。
  1. 获取 Apple ID · 第二阶段（建议）：每位 iOS 中国同事注册自己的美区 ID，详细教程见 §4。
  2. 下载 Loon：在美区 App Store 搜索 Loon，售价 $7.99（约 ¥58，一次性买断）。下载后用 Thomas 发放的订阅链接导入节点。
  3. 导入订阅：参考一分机场 Loon 视频教程。配置流程：复制订阅链接 → Loon 主页 → 配置 → 添加 → 粘贴 → 启用。
  4. 验证：打开 Safari 访问 youtube.com，能加载首页即成功。
注意：Loon 配置导入参考通用 Clash 系列教程；如与 Loon 官方文档有差异，以 Loon 应用内使用说明为准。

2.2 命名规范建议

核心原则：邮箱名看起来是一个规范的名字，而不是随便取的。

关于「韦氏拼音」：下面给的是韦氏拼音风格的样例，是为了避免出现重复名导致 Gmail 申请不到那个用户名 —— 拼音变化越多越不容易撞名。这不是强制要求用韦氏拼音，任何「姓在前名在后」的规范格式都行，关键是让别人一眼看上去专业、好记。

印尼销售代表 1 · 韦氏拼音风格

rep1.tsai-ting@gmail.com
备选：tsai-ting.rep1@gmail.com

印尼销售代表 2 · 韦氏拼音风格

rep2.hung-li@gmail.com
备选：hung-li.rep2@gmail.com
命名格式约束：用户名只允许出现一个点（.）作为姓名分隔符，例如 rep1.tsai-ting@gmail.com。避免出现 xxx.yyy.zzz 这类多点用户名，部分海外服务会拒绝过长的用户名，建议保留 6-15 个字符以内。

4 美区 Apple ID 注册教程（每位 iOS 中国同事必备） ▶
前置条件：注册美区 Apple ID 之前，必须先连上 VPN 并选美国节点，否则注册流程会被卡住或地区无法切换。

4.1 为什么必须有自己的美区 ID

  1. 用 Thomas 的 ID 会被 Apple 安全风控（异地多人登录）
  2. 后续维护账号、找回密码不便
  3. 一旦 ID 被封，影响所有共享的同事

4.2 前置准备

  • 一个干净的邮箱（QQ 邮箱英文版 / Gmail）
  • 国内手机号（用于接收 Apple 验证码）
  • VPN 已连接并选了美国节点（关键）
  • 美区免税州地址生成器（推荐 us.2kz.net）

4.3 注册流程（手机端，最方便）

  1. 确认 VPN 已连接、美国节点已选中（先连 VPN 再注册，否则会卡住）
  2. 打开 Safari，访问 appleid.apple.com/account
  3. 填写信息：姓名英文/拼音、邮箱未被注册过、密码 8 位以上、国家/地区先选中国大陆、生日真实、手机号国内
  4. 完成邮箱验证码 + 手机验证码，注册成功
  5. 关键步骤：登录 appleid.apple.com → 个人信息 → 国家/地区 → 选 United States → 付款方式选 None（无）→ 账单地址用免税州地址生成器
  6. 验证：打开 App Store，登录新 ID，能看到美区应用即成功

4.4 教程参考

  • 机场 WIKI（图文）：wiki.yfjc.win/#article=a23
  • 综合视频/图文教程中心：web.netwiki.link

5 AI Agent 实操作业 · 三位同事共同 ▶

5.1 作业一：电脑端与手机端互联

目标：用手机 MiniMax App 远程操控电脑 MiniMax Agent。

  1. 电脑端 MiniMax Agent → 设置 → 连接手机 → 显示二维码
  2. 手机 MiniMax App → 扫一扫 → 绑定电脑
  3. 测试：在手机上发指令，验证电脑是否执行
验收标准：手机发指令，电脑端能在 30 秒内响应并执行。

5.2 作业二：配置 MiniMax 操控企业邮箱

目标：让 MiniMax（Mavis）能操控公司腾讯企业邮箱，实现「给 MiniMax 发指令 → 自动生成草稿 → 人工确认后发送」的工作流。

怎么做：不用手把手跟教程，直接打开电脑端 MiniMax 对话框，跟它说：

「请帮我配置腾讯企业邮箱 IMAP/SMTP 接入，目标邮箱是 [你的嘉豪企业邮箱地址]，需要先生成草稿、人工确认后再发送，不要直接发邮件。」

然后跟着它的提示一步步完成设置就行。过程中遇到任何报错或者不确定的，把错误信息贴给它，让它帮你排查。

核心约束（务必在配置时跟 MiniMax 说清楚）：

  • 默认走「先生成草稿 → 人工确认后才发送」流程
  • 不要授权 MiniMax 直接发送邮件给客户

5.3 作业三：增加员工 + 理解 CEO 派任务模式

MiniMax Agent（Mavis）支持「CEO + 多个员工 Agent」的协作模式。这个模式解决一个问题：复杂任务一个人忙不过来，拆给多个 AI 员工并行干更快。

👤
CEO
接收任务、评估、分配、协调
→
🤖
员工 Agent
研究/翻译/法务/编程
→
📊
汇总
CEO 整合给到你

具体玩法 — 创建翻译员工 + 法务员工：

  1. 打开 MiniMax Agent → 左侧「专家」或「技能」页面 → 点击新建专家，创建两个
  2. 翻译员工：专长中英双向翻译、海外客户邮件回复；工具：可调用 ChatGPT / DeepL；工作流：接收英文邮件 → 自动起草回复 → 给你确认
  3. 法务员工：专长印尼/中东合同审核、合规检查；工具：合同模板库、风险关键词库；工作流：上传合同 → 标记风险条款 → 输出审核报告
  4. 测试 CEO 派任务：在 MiniMax 对话框输入指令，让它把印尼客户的英文合同翻译成中文并标出风险条款。观察 MiniMax 是否自动调用了翻译员工和法务员工，最终输出合并结果
验收标准：能描述出 CEO → 员工 → 汇总的工作流，并解释为什么这个模式比单 AI 更好用。

Part 6 · FAQ

常见问题 · 6 个

踩过的坑提前讲，省得返工。

网络配置好了但 YouTube 还是加载不出来？
① 切换节点试试；② 检查订阅链接是否过期（联系 Thomas 重发）；③ 检查是否开启了系统代理。
Loon 下载后提示未受信任的开发者？
设置 → 通用 → VPN 与设备管理 → 信任 Loon 开发者。
美区 ID 注册时提示邮箱已被使用？
这个邮箱之前注册过 Apple ID。换个邮箱，或用全新 Gmail。
MiniMax 订阅比 ¥50 贵怎么办？
先用免费版，用量按需付费，观察两周再决定。个人用户 ¥30-50 基础套餐通常够用。
手机端 MiniMax 连不上电脑端？
① 确保两台设备登录同一账号；② 电脑端防火墙允许 MiniMax Agent 通过；③ 重新扫码绑定。
销售助理也需要注册美区 Apple ID 吗？
不需要。销售助理在印尼，印尼区 Apple ID 已经能下载非常多常用软件（包括 Loon 等），无需特殊账号。美区 Apple ID 只针对使用 iOS 系统的中国同事。
